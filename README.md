# Pixel Dimmer

Simple, pure-black (`#000000`) OLED overlay app for Android (built for Galaxy S23 Ultra) to mask punctured edge pixels and dim horizontal screen lines across all apps.

## Download Ready-to-Install APK

- **[Download Latest PixelDimmer.apk](https://github.com/DALI951/pixel-dimmer/releases/latest/download/PixelDimmer.apk)**

## How to Use

1. **Install `PixelDimmer.apk`** on your phone and open **Pixel Dimmer**.
2. **Choose Mode (`Dot` / `Line` / `Both`)** and adjust size with the slider (`Dot` size `2–160 px`, `Line` thickness `1–40 px`).
3. **Hold & drag anywhere** on the white screen:
   - A **6× Zoom Loupe** pops up right next to your target pixel/line with a pixel grid and red screen-edge line.
   - Drag slowly (`0.25×` Fine mode by default) without your finger covering the damaged pixel, or tap/hold `◀ ▲ ▼ ▶` for 1-pixel nudges.
4. **Flip `Mask ON`** and allow **Appear on top** once so the pure-black mask stays floating over every app (all touches pass right through it).
5. *(Optional)* Tap **⚙ → Full-Cover (A11y)** if you also want the mask to cover the top status bar and system dialogs, or add the **Pixel Dimmer** Quick Settings tile from your notification shade.
